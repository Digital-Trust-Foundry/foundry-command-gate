# Security

Please report a security issue in the Foundry Command Gate privately, by email to info@digitaltrustfoundry.com, rather than in a public issue. Include the version from `.claude-plugin/plugin.json`, what you ran, and what happened.

The gate is a checkpoint for the commands Claude Code runs, not a sandbox. The README lists what it does not see. A way to run a gated command that the gate neither stops nor refuses, or a way to reuse an approval, is a security issue.
